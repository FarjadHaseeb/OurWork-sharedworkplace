# Our Work

A real-time collaborative task management workspace built with React and Supabase.

## Overview

This is made as just for the personal use for friends, doing the daily tasks. Our Work is a collaborative task management application designed for small teams. It allows team members to create, assign, track, discuss, complete, delete, and restore shared tasks from a single dashboard.

## Features

- Create shared tasks
- Assign tasks to team members
- Set task priority
- Add task descriptions and instructions
- Track Pending, Ongoing, and Completed tasks
- Start and complete tasks
- Reopen completed tasks
- Real-time task synchronization using Supabase Realtime
- Task comments and discussions
- Task progress percentage
- Member-based task filtering
- Task stopwatch
- Audit activity log
- Deleted task trash
- Restore deleted tasks
- Permanently delete tasks from local trash
- Responsive modern UI
- Dark glassmorphism interface
- Animated custom cursor
- Completion confetti animation

## Technology Stack

- React
- JavaScript
- Supabase
- Tailwind CSS
- HTML
- CSS
- LocalStorage
